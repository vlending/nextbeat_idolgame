# 넥스트비트 데뷔 프로젝트

연습생 4명을 2년(24개월) 안에 음원차트 1위 걸그룹으로 키우는 모바일 육성 게임입니다.
설치 없이 `index.html` 파일 하나를 휴대폰/PC 브라우저로 열면 바로 플레이할 수 있습니다.

## 멤버
| 이름 | 포지션 | 특징 |
|---|---|---|
| 한서윤 (20) | 리더 · 메인보컬 | 보컬 레슨 효과 1.3배 |
| 강하린 (19) | 메인댄서 | 댄스 레슨 효과 1.3배 |
| 윤채아 (18) | 비주얼 · 센터 | 연기·화보 수업 효과 1.3배 |
| 오지우 (16) | 래퍼 · 막내 | 모든 수업 효과 1.1배 |

## 진행 방식
1. 매달 멤버 카드를 눌러 일정(보컬/댄스/연기·화보/아르바이트/SNS 라이브/휴식)을 정합니다.
2. **이번 달 진행** → 능력치·컨디션·팬·자금이 변하고, 랜덤 사건이 생기면 선택지를 고릅니다.
3. 평균 능력치 30 이상(3월 이후)이면 **데뷔 쇼케이스**, 이후 3개월마다 **컴백 무대**.
4. 컨셉(청량/걸크러시/몽환/레트로)과 멤버 능력치 궁합 + 팬 수 + 컨디션으로 차트 순위가 정해집니다.
5. 매달 멤버와 대화하면 호감도가 오르고, 호감도가 높을수록 레슨 효과가 커집니다.
6. 24개월 후 최고 순위로 S~F 등급 엔딩.

진행 상황은 브라우저에 자동 저장됩니다.

## 수정 포인트 (개발자용)
`index.html` 안의 `MEMBERS`(캐릭터 이름·능력치·대사·머리색), `SCHED`(일정), `CONCEPTS`(컨셉), `EVENTS`(사건) 목록만 고치면 내용을 바꿀 수 있습니다.
