# 넥스트비트 데뷔 프로젝트

설치 없이 `index.html` 파일 하나를 휴대폰/PC 브라우저로 열면 바로 플레이할 수 있습니다.

## 진행 방식
1. 매달 멤버 카드를 눌러 일정(보컬/댄스/연기·화보/아르바이트/SNS 라이브/휴식)을 정합니다.
2. **이번 달 진행** → 능력치·컨디션·팬·자금이 변하고, 랜덤 사건이 생기면 선택지를 고릅니다.
3. 평균 능력치 30 이상(3월 이후)이면 **데뷔 쇼케이스**, 이후 3개월마다 **컴백 무대**.
4. 컨셉(청량/걸크러시/몽환/레트로)과 멤버 능력치 궁합 + 팬 수 + 컨디션으로 차트 순위가 정해집니다.
5. 매달 멤버와 대화하면 호감도가 오르고, 호감도가 높을수록 레슨 효과가 커집니다.
6. 24개월 후 최고 순위로 S~F 등급 엔딩.

7. **무대 리듬게임**: 컴백 때 배경음악(115 BPM)에 맞춰 떨어지는 노트를 멤버 칸에서 터치합니다. 정확도에 따라 무대 점수가 최대 +68 / 최소 -82 달라지고, PERFECT가 가장 많은 멤버가 MVP가 됩니다. 건너뛰면 점수 변화가 없습니다. PC에서는 D·F·J·K 키를 씁니다.
8. **투자**: 시설·계약(영구: 레슨 효과 +2, 휴식 회복 +15, 홍보팀 팬 1.5배)과 다음 무대 준비(뮤직비디오, 의상, 작곡가: 무대 점수 +15~+50)에 돈을 씁니다.
9. **라이벌 차트**: 민트시럽 → 스텔라코드 → 오로라나인 → 크라운 순으로 라이벌이 차트에 있습니다. 무대 순위가 라이벌보다 높으면 격파하고 팬 보너스를 받습니다.

10. **멤버 이야기**: 호감도 30·60·90에서 멤버별 이야기(총 12편)가 열립니다. 선택지에 따라 보상이 달라지고, 3편을 모두 보면 특별 능력이 생깁니다.
    - 도린 「숨은 배려」 매달 컨디션이 가장 낮은 멤버 +8 · 가람 「진짜 웃음」 SNS 팬 1.5배·매력 수업 +2
    - 세온 「무대 체질」 무대에서 컨디션 영향 없음·점수 +15 · 리에 「관찰 노트」 리듬게임 판정 범위 확대
11. **멤버별 엔딩**: 이야기 진행·선택·호감도에 따라 멤버마다 트루/일반/아쉬운 엔딩이 나옵니다. 네 명 모두 트루 엔딩 + 1위면 그룹 트루 엔딩 「같은 비트, 다른 나」.

12. **자동 운영**: 운영 스타일(실력 우선 · 팬덤 우선 · 안정 운영 · 균형)을 고르면 매니저가 매달 일정·투자·사건 선택을 알아서 합니다. 멤버 이야기가 열리면 멈추고 대표님의 선택을 기다립니다. 무대는 직접 하기(리듬게임)·자동 중에 고릅니다. 매니저의 안부 챙기기는 호감도 +2(직접 대화 +5)라서, 직접 대화를 섞으면 이야기가 더 빨리 열립니다.
    - 테스트(무대 자동): 실력 우선·균형은 20~23개월 차 1위, 안정 운영은 17위권(대신 컨디션 관리가 좋아 이야기가 많이 열림), 팬덤 우선은 20위권.

13. **특훈 미니게임** (멤버 화면, 매달 1회): 점수에 따라 해당 능력치 +1~+6, 90점 이상이면 호감도 +5. 자동 운영에서는 하지 않습니다.
    - 음정 맞추기(보컬): 기준음을 듣고 움직이는 음이 같은 높이일 때 멈추기, 5라운드
    - 박자 감각(댄스): 메트로놈 4박 뒤 소리 없는 4박에 맞춰 터치, 100→115→130 BPM 3라운드 (스피커 지연 자동 보정)
    - 멜로디 기억(매력): 도·미·솔·높은 도 멜로디 따라 누르기, 3음→7음 5라운드

밸런스 참고(자동 플레이 테스트): 리듬게임을 건너뛰고 투자하지 않으면 최고 50~60위권, 투자와 대화를 하고 리듬게임을 85% 정도 맞히면 21개월 차쯤 1위에 도달합니다.

진행 상황은 브라우저에 자동 저장됩니다.

- X, Threads, Facebook, LINE 공유 링크와 공유 글 복사 버튼을 제공합니다. 인스타그램·카카오톡은 저장한 이미지와 복사한 글을 붙여 올리는 방식입니다.
- 직접 서버에 올려 쓰는 경우, 지원하는 휴대폰에서는 **이미지와 함께 공유** 버튼이 나타납니다.
- 공유 글에 들어가는 게임 주소는 `index.html`의 `SHARE_URL`에서 바꿉니다.

## 수정 포인트 (개발자용)
`index.html` 안의 `MEMBERS`(캐릭터 이름·능력치·대사·머리색), `SCHED`(일정), `CONCEPTS`(컨셉), `EVENTS`(사건) 목록만 고치면 내용을 바꿀 수 있습니다.

## 🔮 고양이 타로 상담 (`tarot.html`)
타로 고양이 「루나」가 **목소리로 대화하며** 타로를 봐 주는 페이지입니다. 육성 게임 첫 화면의 「고양이 타로 상담」 버튼이나 `tarot.html`로 들어갑니다.

1. **상담 시작** → 고양이가 말로 인사합니다.
2. **질문하기**: 🎤 버튼을 누르고 말하거나 글로 적습니다. 예시 질문을 눌러도 됩니다.
3. **카드 고르기**: 메이저 아르카나 22장 중 3장 → 과거 · 현재 · 미래.
4. **해석 듣기**: 고양이가 카드를 한 장씩 뒤집으며 말해 줍니다. 말할 때 입이 움직이고, 카드 분위기에 따라 표정(기본·웃음·활짝·진지·놀람)이 바뀝니다. 자막을 누르면 건너뜁니다.
5. **종합 해석 + 추가 대화**: 추가 질문 3번, 카드 1장 더 뽑기, 대화 기록 다시 듣기.

### AI 해석 (API 키 넣는 곳)
- 화면 오른쪽 위 **「AI 설정」** → Claude API 키 입력 → 「연결 테스트」 → 「저장하기」. 키는 [Anthropic 콘솔](https://console.anthropic.com/settings/keys)에서 만듭니다.
- 모델 선택: Claude Opus 5.5(기본, 해석이 가장 깊음) · Sonnet 5.5(더 빠르고 저렴) · Haiku 5.5(가장 빠르고 저렴).
- 키가 있으면 AI가 질문에 맞춰 카드 해석·종합 해석·추가 답변을 직접 만듭니다. 키가 없거나 AI 연결이 실패하면 미리 써 둔 기본 해석(카드 22장 × 주제 5종)으로 자동 진행됩니다.
- 키는 그 브라우저에만 저장됩니다. 운영자가 `tarot.html` 안의 `CONFIG.apiKey`에 직접 넣을 수도 있지만, 그러면 페이지를 연 누구나 키를 볼 수 있으니 혼자 쓸 때만 쓰세요. 일반 사용자에게 공개할 때는 키를 서버에 두는 방식으로 바꿔야 합니다.
- 고양이 이름은 `CONFIG.catName`에서 바꿀 수 있습니다.

### 음성
- 목소리: 브라우저 내장 한국어 음성을 높은 톤으로 씁니다(기기마다 다르게 들림). 상단 🔊 버튼으로 끄면 자막만 나옵니다.
- 음성 입력: 크롬 · 사파리 · 삼성 인터넷. 처음 한 번 마이크 허용이 필요하고, 지원하지 않는 브라우저에서는 글로 입력합니다.
